### F5 Send Report spec
A PDF report generator that composes selected PortfolioLens sections into a printable/emailable document.

**Sections to include (user toggles each on/off):**
- Portfolio summary (E1 — holdings value, XIRR, LTCG hint)
- Allocation breakdown (E2 — category/AMC table + donut)
- Holdings table (E3 — scheme-level with XIRR)
- Capital gains summary (E7 — realised/unrealised, LTCG/STCG)
- Health check score (F1 — score + rule summary table)
- Rebalance plan (F3 — reads fundlens_rebalance_plan_v1 if saved)

**Behaviour:**
- Section toggles: checkboxes for each included section
- Preview pane: live HTML preview of the report in the browser
- "Download PDF": uses browser `window.print()` with a print-specific CSS (`@media print`) — no server round-trip, no third-party PDF library
- "Email draft": composes a mailto: link with report summary in the body (plain-text subset — DPDP safe)
- Report header: FundLens logo (text), portfolio name, generated date (fmtDate())
- Report footer: "Generated by FundLens · fundlens.in · Data processed locally · Not investment advice"
- Advisor mode: show firm name + logo in header instead of FundLens branding (reads from advisor_profiles stub)

**DPDP compliance:**
- PAN/name never in report (show last 4 chars only if present, or redact entirely)
- Folio numbers never shown in report
- Report generation is 100% local — no network calls

**UI:**
- Two-column layout: left = section toggle panel; right = live preview iframe/div
- Mobile: single column, toggles above preview
- "Download" button prominent (primary ACC green)
- Section toggles: checkbox + section name + short description
