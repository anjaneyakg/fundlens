# CLAUDE.md — fundlens repo rules

## Project status log

Before ending any session that completed or changed a module, feature, bug fix, schema, workflow or infrastructure item: add a dated entry to `docs/PROJECT_STATUS.md` in the private FundInsight repo (newest first: date, what changed, why, files, commit hash, follow-ups), update the Module status table and Open items, then commit and push it.
Never write secrets, keys, passwords or tokens in that file.
